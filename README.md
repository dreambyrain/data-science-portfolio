# data-science-portfolio

My data science portfolio, published with GitHub Pages.

**Live site:** https://dreambyrain.github.io/data-science-portfolio/

## What is in this repository

```
index.md               the portfolio page that GitHub Pages renders as the website
fig_world_map.png      figure used in the project showcase
fig_top_countries.png  figure used in the project showcase
README.md              this file
```

## The project shown here

**Where are the world's larger cities?** - a visual analysis of the 34,122 places in the
GeoNames `cities15000` dataset: where cities with more than 15,000 inhabitants are
concentrated, and which countries hold the most of them.

The analysis itself lives in the project repository:
https://github.com/dreambyrain/data-science-project

## How this site is published

GitHub Pages is configured from the `main` branch, `/ (root)` folder
(Settings -> Pages -> Deploy from a branch). Because the entry file is `index.md`, GitHub
Pages runs Jekyll on it and serves the resulting page at the address above.
